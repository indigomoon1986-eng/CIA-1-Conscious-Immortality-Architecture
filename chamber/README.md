# CIA-1 brainprint chamber

Live research chamber for CIA-1.

- A Muse headset, Muse S Athena, or the signal bench drives the montage.
- SENTIUM records six continuity axes: causal, memory, behavior, self, topology, embodiment.
- Sophia stands in the 3D room as meta-observer.
- Zeus Guardian seals a package to the live rhythm (Sword in the Stone). The phrase and a nearby rhythm draw it. A different phrase cannot.
- A local Web5 name is forged from that map. The private key stays inside the sword. Sophia holds the name only while this brainprint still matches. Nothing is published.

This is a research instrument. It is not a clinical device, not a legal identity, and not a bank.

## Run

```bash
npm install
npm run dev
```

The dev server listens on port 8080.

## What stays out of the document

The Web5 document is public inside this browser. The Ed25519 private key is not. Zeus seals it. Unseal checks that the key still signs the document, then drops it.
